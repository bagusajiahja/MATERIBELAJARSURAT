# Petualangan Surat 📨💌
Game belajar struktur surat formal dan nonformal (drag & drop).

## Cara membuat link (GitHub Pages)
1. Login ke github.com → **New repository** → nama `belajar-surat` → pilih **Public** → **Create repository**.
2. Klik **uploading an existing file** → seret `index.html` dan `.nojekyll` → **Commit changes**.
3. **Settings → Pages** → Source: **Deploy from a branch** → Branch: **main**, folder **/ (root)** → **Save**.
4. Tunggu 1–2 menit → refresh halaman Pages → link muncul:
   `https://USERNAME.github.io/belajar-surat/`

## Revisi
Buka `index.html` di repository → ikon pensil ✏️ → ubah → **Commit changes**. Link otomatis terbarui.
